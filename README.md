

# EMPLOYEE MANAGEMENT SYSTEM

A simple employee management application built with Python to manage employee records and calculate total salary expenses.

## About

This project is a menu-driven, console-based application that allows users to add employee information, view employee records, and calculate the total salary expense of all employees.

It uses Python lists, dictionaries, functions, loops, and conditional statements to manage employee information.

## Features

- Add a new employee
- Enter employee name, age, and salary
- Display all employee records
- Calculate total salary expenses
- Menu-driven interface
- Handle invalid menu choices
- Exit the application

## How It Works

### 1. Add Employee

The user enters an employee's name, age, and salary. The program stores these details in a dictionary and adds it to the employee list.

### 2. Show Employees

The program displays the details of all employees currently stored in the list.

### 3. Total Salary Expense

The program calculates and displays the combined salaries of all employees.

### 4. Exit

The user can select the exit option to stop the program.

## How to Run

1. Clone or download this repository.
2. Open the project folder in your code editor.
3. Make sure Python is installed.
4. Run the following command in the terminal:

```bash
python EMPLOYEE_MANAGEMENT_SYSTEM.py
```

## Data Storage

Employee records are stored in a Python list using dictionaries. The data is kept in memory and is not permanently saved to a file or database.
